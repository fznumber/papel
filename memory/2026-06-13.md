### trimesh.contains() engaña
- Para barrel_block.obj (sólido con hueco), `contains()` retorna TRUE para el material, NO para la cavidad
- Las partículas se colocaban dentro de la pared del barril, no en el bore
- Solución: usar shapely `contains_xy()` + `trimesh.proximity.signed_distance()` para filtrar

### Partículas: 6108 generadas, 5344 estables

- Las 5344 restantes son estables: velocidad baja de ~20 m/s (frame 1) a ~1 m/s (frame 3)
