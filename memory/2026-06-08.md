- Screw right: dinámico en [C/2, 0, 0], rotación inicial 180°
- Motor joints: -10.5 rad/s, eje [0,0,1]
- Notch tracking: ~20°/frame a 30FPS = 10.5 rad/s exacto ✅

**Problema: fuga por tapas del barril**
- Fluid blocks cerca de los extremos del barril → la rotación de los tornillos bombea fluido a través de las tapas
- Gap tornillo-barril (0.15mm) < particle radius (1mm) → partículas no pueden fluir por el gap, se comprimen y escapan
- La fuga es endémica: ocurre en los primeros 2 frames (~0.067s) independientemente de mapThickness

**Causa raíz**: el gap de 0.15mm requiere partículas < 0.075mm para resolverse → ~42M partículas para el barril completo. Inviable con CPU build.

## Lecciones aprendidas
1. **Motor joints funcionan perfectamente**: -10.5 rad/s objetivo, medición ~10.5 rad/s real
2. **Self-wiping profile**: boundary r(θ) = C·cos(θ) - sqrt(R²−C²·sin²θ) para θ∈[−θ_int,θ_int], r=R fuera
3. **Dynamic rigid bodies + VolumeMap**: 2.1ms/step con 504 partículas y 3 boundaries
4. **Neighbor search bottleneck**: computeVolumeAndBoundaryX escala aproximadamente lineal con particle count
5. **Gap resolution**: gap de 0.15mm requiere partículas < 0.075mm → inviable sin GPU. Alternativa: simulación 2D (cross-section)
